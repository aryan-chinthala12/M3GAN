# Sample Data

Place short voice recordings here (WAV / MP3 / FLAC / M4A / WEBM / OGG) to
test the audio pipeline without a microphone.

## Where to get test audio

1. **Record your own** (recommended for the demo): use the dashboard's
   Live Assessment page — it records straight from the mic, or any phone
   voice-recorder app; export and drop the file here.
2. **Emotion datasets** (for richer demos of angry/fearful/sad speech):
   - RAVDESS — https://zenodo.org/records/1188976 (audio-only speech files)
   - TESS — https://borealisdata.ca/dataset.xhtml?persistentId=doi:10.5683/SP2/E7H2MF
   - CREMA-D — https://github.com/CheyneyComputerScience/CREMA-D

   Pick a few `fearful`/`angry`/`sad` clips; a 3–8 second WAV per emotion
   is plenty for a demo.

## Sample narratives (for the Text / Chat assessment mode)

Multilingual test narratives are also provided as text files in this folder
and are pre-wired as one-click samples on the Live Assessment page:

- `sample_hindi_romanized.txt` — intimidation + social boycott (Romanized Hindi)
- `sample_english_severe.txt` — sexual violence + suicidal ideation (English)
- `sample_tamil_fear.txt` — fear + displacement (Tamil)
- `sample_english_benign.txt` — routine grievance (low-risk control)

Use the "Text / Chat" tab on the Live Assessment page and paste any of these
to see the full SVI pipeline without any audio at all.
